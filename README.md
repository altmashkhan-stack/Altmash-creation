## 📖 Overview

**Altmash Creation** is a modern, responsive single-page portfolio website designed for a digital creator. It highlights services, showcased work, and provides an easy way for clients to get in touch — all wrapped in a visually rich, animated interface with a gold-and-purple aesthetic.

---

## 🚀 Features

- 🎨 **Modern UI** — Glassmorphism cards, animated gradient blobs, and smooth scroll-reveal transitions
- 📱 **Fully Responsive** — Optimized layout for mobile, tablet, and desktop
- 🧭 **Smooth Navigation** — Fixed navbar with anchor links and a mobile slide-in menu
- 🖼️ **Portfolio Filter** — Filter work by category (All / Design / Edits / Posters)
- 💬 **Contact Section** — Direct WhatsApp link, phone number, and a contact form
- 📸 **Social Integration** — Quick links to Instagram and other socials
- ⚡ **Lightweight & Fast** — Pure front-end stack, no heavy dependencies
- ✨ **Icon Support** — Crisp SVG icons powered by Lucide

## ⚙️ Getting Started

### Prerequisites
No installation required — this is a static website.

### Run Locally

```bash
# Clone the repository
git clone https://github.com/altmashkhan-stack/Altmash-creation.git

# Navigate into the project folder
cd Altmash-creation

# Open index.html directly in your browser
# or use a local dev server, e.g.:
npx serve .
```

Then open `http://localhost:3000` (or the shown port) in your browser.
